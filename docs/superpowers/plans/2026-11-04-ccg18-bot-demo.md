# CCG 18 bot demo - Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bot Telegram + panou web pentru CCG 18: intrare cu numărul de telefon, vot, anunțuri, convocare, cotizații (QR demo), sesizări.

**Architecture:** Un singur proces Python: FastAPI servește panoul și pornește în `lifespan` polling-ul aiogram. Logica de domeniu stă în module pure peste `sqlite3` (testate cu pytest pe DB în memorie); handler-ele bot și rutele web sunt subțiri.

**Tech Stack:** Python 3.12, aiogram 3.x, FastAPI, Jinja2, uvicorn, sqlite3 (stdlib), qrcode[pil], itsdangerous, pytest.

**Spec:** `docs/superpowers/specs/2026-11-04-ccg18-bot-design.md`

## Global Constraints
- Fără em-dash/en-dash (U+2014, U+2013) în cod și texte; doar `-`.
- Secretele (`BOT_TOKEN`, `SECRET_KEY`) doar în `.env`; `.env` în `.gitignore`.
- Telefon normalizat = doar cifre, cu prefix țară, ex. `37300123456`.
- Texte bot în `ro` și `ru`, din `app/i18n.py`.
- Telefoanele nu apar niciodată în procesul-verbal.

## Review Focus
1. Contact trimis care NU e al expeditorului (`contact.user_id != from_user.id`) - refuzat. Test în Task 2.
2. Formate de telefon diferite în listă vs Telegram (`000123456`, `+373 00 123 456`, `37300123456`) - aceeași cheie. Test în Task 1.
3. Dublu-click pe „Confirm” / vot repetat - al doilea refuzat, nu numărat. Test în Task 3.
4. Vot după termen sau pe vot închis - refuzat. Test în Task 3.
5. Vot secret: din DB nu se poate lega membrul de opțiune. Test în Task 3.

### Task 1: Schema, telefon, membri, seed

**Files:** Create `app/db.py`, `app/phone.py`, `app/members.py`, `app/seed.py`, `tests/test_members.py`, `requirements.txt`, `.gitignore`, `.env.example`

- tabele: `members(id, name, phone UNIQUE, telegram_id UNIQUE NULL, lang, is_admin)`, `garages(id, number UNIQUE, row_label, member_id)`, `votes(id, title, description, options_json, weight_mode 'member'|'garage', secret 0|1, deadline TEXT ISO, status 'open'|'closed', created_at)`, `vote_cast(vote_id, member_id, entered_by NULL, cast_at, PK(vote_id,member_id))`, `vote_choice(id, vote_id, option_idx, weight, member_id NULL)`, `notices(id, kind 'anunt'|'convocare', title, body, row_label NULL, file_path NULL, created_at)`, `notice_delivery(notice_id, member_id, delivered_at, ack_at NULL)`, `dues(id, garage_id, period, amount, paid_at NULL)`, `reports(id, member_id, text, photo_file_id NULL, status 'nou'|'rezolvat', created_at)`, `admin_tokens(token, member_id, expires_at)`
- `phone.normalize(raw: str) -> str`
- `members.find_by_phone(conn, raw) -> Row|None`, `members.link_telegram(conn, member_id, telegram_id)`, `members.by_telegram(conn, tg_id) -> Row|None`, `members.garages(conn, member_id) -> list[Row]`, `members.import_csv(conn, text) -> int` (coloane `nume,telefon,garaje,rand`, garaje separate prin `;`), `members.set_lang(...)`

### Task 5: Bot Telegram

**Files:** Create `app/i18n.py`, `app/bot.py`, `tests/test_i18n.py`

**Interfaces - Consumes:** Task 1-4. **Produces:** `bot.build(conn, settings) -> (Bot, Dispatcher)`; `bot.broadcast_notice(bot, conn, notice_id)`, `bot.broadcast_vote(bot, conn, vote_id)` (apelate din panou).

Flux: `/start` -> alegere limbă (inline ro/ru) -> tastatură cu buton `request_contact` -> `auth.login_contact` -> meniu principal (reply keyboard): Voturi · Cotizații · Sesizare · Anunțuri. Vot: buletin cu butoane opțiuni -> ecran de confirmare -> `votes.cast` -> chitanță cu garajele. Convocarea are buton „Am luat la cunoștință” -> `notices.ack`. Sesizare: stare FSM, text și/sau poză. `/panou` pentru admini -> link `{BASE_URL}/login/{token}`.

- [ ] Test: fiecare cheie din `i18n.T["ro"]` există și în `T["ru"]`; niciun text nu conține U+2014 sau U+2013.
- [ ] Implementare; verificare manuală pe Telegram real (tokenul proprietarului), commit.
